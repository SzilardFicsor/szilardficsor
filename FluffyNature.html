Fluffy Nature

Overview

Fluffy Nature is a HDRP project composed out of different shaders working together to create a stylised nature landscape.

This project features a collection of interesting shaders:

  • Extensive grass shader with multiple variations.

  • Tree shader.

  • Water Shader.

  • Triplanar rock shader.

This project was made with Unity.
