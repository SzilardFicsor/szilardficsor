Animated Robot

Overview

This is a game ready, optimized and animated character. The concept for this project was a robot that has a profession, which is in this case a mining robot. It was a great exercise for low-poly modeling, PBR workflow, rendering and presentation.

This project was created with the following tools:

  • Blender - low poly modeling and animation.

  • Substance Painter - Texturing.

  • Blender and Unity - Rendering and presentation.
